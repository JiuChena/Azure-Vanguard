# 其他基建（相机/音频/场景/计时/VFX/Shader/Core.Expand）

除另有详文外的 Core.Gear 子系统与项目级基建，一篇收纳。路径均在 `Assets/Scripts/CSharp/Core/Gear/` 下（另注明者除外）。

## 相机管理（CameraManager，2026-10-05）

`Common/CameraManager.cs`（MonoBehaviour 单例）+ 键枚举 `CameraType`（同目录，现仅 Main/UI，按需扩充）。

- **Inspector 预配置 = 双列表** `inspectorKeys`/`inspectorValues`（下标一一对应）。**未复用 `SerializableDictionary`**：注销需要 Remove、导入需要枚举，框架类两者皆无，扩框架属高风险需另征同意，遂按用户"双列表模拟"口径在 Manager 内自持
- **运行时唯一事实源**：Awake 把 Inspector 配置全量导入私有 `Dictionary<CameraType, Camera>`，此后注册/注销只动运行时表，**不回写序列化数据**（避免 Play 模式污染场景/Prefab）。导入时空值 LogError 跳过、重复键 LogWarning 后者覆盖、长度不齐 LogError 按短侧导入
- **API**：`Register(type, camera)`（空相机拒绝；覆盖已有键 LogWarning）/ `Unregister(type)`（未注册告警返 false）/ `Get(type)`（失败 LogError 返 null）/ `TryGet(type, out camera)` / `ContainsKey(type)`
- **Unity-null 自愈**：命中键但相机已销毁（如随场景卸载）→ `TryGet` 清脏条目并告警、按未注册处理；`Get`/`ContainsKey` 同口径
- 使用：管理物体挂 `CameraManager` 并在 Inspector 填键值对，或运行时 `CameraManager.Instance.Register(...)`

## 场景加载（LoadSceneManager）

`SceneLoader/LoadSceneManager.cs`：`LoadSceneManager.Instance.LoadSceneAsync(场景名)`；进度经 `EventNames.LoadSceneProgress` 广播（PreloadPanel 订阅刷新进度文本）。

## 加载进度汇聚（LoadProgressHub）

`LoadProgress/LoadProgressHub.cs`——多路加载进度汇聚上报。

## 音频（AudioManager）

`AudioModuleManager/AudioManager.cs`：`AudioManager.Instance.SetAudio(...)` 播放；**禁原生 `AudioSource.Play()`**（背景视频自带的 AudioSource 除外，属 AV 硬件通道）。音频设置存档域见 [[04-模块/玩家数据中心]]。

## 每帧更新挂载点（PublicMono）

`Common/PublicMono.cs`：`PublicMono.Instance.AddListener(...)` 注册每帧回调；**仅为拿 Update 而新建 MonoBehaviour = 禁区**。

## 计时（Timer / TimerEvent）

`Timer/Timer.cs` + `TimerEvent.cs`：定时回调；**禁 `Invoke()` / 协程 WaitForSeconds**。

## 特效池（VFXPool）

`VFXPool/VFXPool.cs` + `VFXPoolHost.cs`：特效对象池，宿主 MonoBehaviour 负责回收。

## 交互（Interaction）

`Core/Gameplay/Interaction/`——`Interactable.cs` / `InteractOption.cs` / `InteractSearcher.cs`：交互发射器 + 可交互接口，禁逐对象手写交互检测。UI 侧辅助：`Bissness/UI/Item/General/InteractionAudioHelper.cs`。

## Core.Expand（Unity 类型扩展注入）

`Assets/Scripts/CSharp/Core/Expand/`：给 Unity 现有无法修改的类注入外部函数。约定：**每个扩展方法单开一个脚本**，统一聚合在 `{类型名}Expand` 的 static partial 类，namespace `Core.Expand`。

| 文件 | API | 说明 |
|------|-----|------|
| `TransformLocalTransformReset.cs` | `transform.LocalTransformReset()` | localPosition 归零、localRotation 归位、localScale 归一（2026-09-24） |

Button 回调栈（点击只执行栈顶、执行即弹出）：已评估可行——扩展方法语法 + `ConditionalWeakTable<Button, Stack<UnityAction>>` 存栈 + 首次 Push 接管 onClick（`onClick` 有 setter；`Press()` 自带 interactable 门控且 Submit 同路径）；方案细节见归档日志 `07-更新日志/归档/2026-09-24.md`，**待用户拍板后动工**。

## Shader（Assets/Shader）

手写 HLSL 约定：中文属性名/注释、URP 包路径 include、材质属性收进 `UnityPerMaterial`（SRP Batcher 要求同一 shader 各 Pass 的 CBUFFER 布局一致）；无 LightMode 标签的 Pass 以 SRPDefaultUnlit 参与前向（描边等附加通道的做法），开关关闭时顶点塌缩成退化三角形不产生像素。

| Shader | 路径 | 要点 |
|--------|------|------|
| GTS/General Toony Shader | `Toony/GTS/GeneralToonyShader.shader` | 全功能卡通渲染：遮蔽/漫反射色阶(VL堆叠)/高光/头发各向异性/边缘光/透光/自发光/描边两模式/半透明，CustomEditor `GeneralToonyShadeEditor` |
| GTS/General Toony Shader Lite | `Toony/GTS/GTSLite.shader`（2026-09-22） | 简化场景版：仅 `_BaseMap` + `_BumpMap`；NL 两阶明暗 ×主光色 + SH 环境光；描边为反向壳 Pass（`_OUTLINE_ON`）。**属性名对齐 URP Lit**，Lit 材质直接换 shader 不丢贴图；ShadowCaster/DepthOnly 借 UsePass |
| Effect/Flow Surface | `Effect/Flow/FlowSurface.shader`（2026-09-22） | 无光照流动表面：UV 偏移 = `xy 速度 × _Time.y`（独立、可负、循环靠贴图 Repeat），自发光 = 贴图 × HDR 色 × 强度，透明混合 ZWrite Off |
