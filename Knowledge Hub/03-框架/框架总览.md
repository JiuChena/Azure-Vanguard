# 框架总览（CoreFramework / Core.Gear）

> 代码根：`Assets/Scripts/CSharp/Core/`。**Core 层类型全部挂在 `Framework.*` / `Core.*` 命名空间下，Bissness 层类型才是全局的**——跨层引用类型前先 grep `^namespace` 确认（漏 using 高发，六次同型翻车教训）。
> 各子系统详文见本目录对应篇；本文是地图不是说明书。

## 硬约定（跨子系统）

- **资源加载只走 AddressableManager**，禁 `Resources.Load`；**持久化只走 BinaryDataManager**，禁 `PlayerPrefs`
- **事件只走 EventCenter**（EventNames 常量），禁自定义 Action 事件
- **热路径禁** `Instantiate/Destroy`（走 ObjectsPool）、`GetComponent/Find/Camera.main`（Awake 缓存）、每帧 `new`
- **UI 面板一律继承 PanelBase**，经 `PanelManager.Instance.PanelDisplay<T>()` / `OpenPanel<T>()` 开关
- 修改 Core.Gear 框架文件属**高风险操作**，必须先征得用户同意
