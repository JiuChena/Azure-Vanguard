# 操作系统基础

## 概述

操作系统知识是游戏开发面试中的常考点，主要涉及进程/线程管理、内存管理、文件系统和锁机制。

## 核心知识点

### 1. 进程与线程

- **进程**: 程序的一次执行实例，拥有独立的内存空间
- **线程**: 进程内的执行单元，共享进程的内存空间
- **Unity 中的线程**: 主线程处理游戏逻辑和渲染，Job System 可以利用多线程

```csharp
// C# 线程示例
Thread t = new Thread(() => {
    // 注意：Unity API 只能在主线程调用
    Debug.Log("This won't work in child thread!");
});
t.Start();
```

### 2. 死锁条件

1. 互斥条件
2. 请求与保持

### 3. 锁机制

| 锁类型 | 特点 |

### 4. 内存管理

- 虚拟内存与物理内存

## 面试高频题

### Q1: 进程和线程的区别？
**难度**: 🟢
**回答**: 进程是资源分配的基本单位，线程是 CPU 调度的基本单位。进程间内存隔离，线程共享进程内存。Unity 是多线程的（主线程 + Job threads + 渲染线程）。

### Q2: 什么是死锁？如何避免？
**难度**: 🟡
**回答**: 死锁是两个或多个线程互相等待对方释放资源。避免方法：按顺序加锁、使用超时机制、避免嵌套锁。
