# 数据结构与算法

## 哈希表 (Hash Table)

### 基本原理

哈希表通过哈希函数将键（key）映射到数组的索引位置，实现 O(1) 平均时间复杂度的查找、插入和删除。

```
key → hash(key) → index → bucket → value
```

### 哈希冲突 (Collision) 及解决方案

当不同的 key 通过哈希函数映射到相同的索引时，发生哈希冲突。

#### 1. 链地址法 (Separate Chaining / Open Hashing)

- 每个桶（bucket）是一个链表（或其他数据结构）
- 冲突的元素追加到链表末尾
- 查找时先定位桶，再遍历链表
- 缺点：链表过长时查询退化为 O(n)

#### 2. 开放地址法 (Open Addressing / Closed Hashing)

当冲突发生时，寻找下一个空闲位置：

- **线性探测 (Linear Probing)**: 依次检查下一个位置 `index + 1, index + 2...`
- **二次探测 (Quadratic Probing)**: 探测步长为平方 `index + 1^2, index + 2^2...`
- **双重哈希 (Double Hashing)**: 使用第二个哈希函数计算步长

### 面试常见问题

- ⚠️ 哈希表的扩容机制及 rehash 过程
- ⚠️ C# 中 `Dictionary<TKey, TValue>` 的内部实现 ⚠️
- ⚠️ 哈希函数的设计原则

## 排序算法

### 时间复杂度为 O(n log n) 的排序

| 算法 | 平均时间 | 最坏时间 | 空间 | 稳定性 | 特点 |
|------|----------|----------|------|--------|------|
| 快速排序 (Quick Sort) | O(n log n) | O(n^2) | O(log n) | 不稳定 | 实际场景最快，最坏情况少见 |
| 归并排序 (Merge Sort) | O(n log n) | O(n log n) | O(n) | 稳定 | 适合外排序，链表排序 |
| 堆排序 (Heap Sort) | O(n log n) | O(n log n) | O(1) | 不稳定 | 原地排序，空间最优 |

### 各排序对比

- **快速排序**: 平均性能最好，分区策略影响性能，可通过随机化避免最坏情况
- **归并排序**: 稳定，适合数据量大的外排序，但需要 O(n) 额外空间
- **堆排序**: 空间最优 O(1)，但常数因子大，缓存不友好

### 其他常见排序

- **插入排序**: O(n^2)，小规模数据或近乎有序时表现好
- **冒泡排序**: O(n^2)，基本用于教学
- **选择排序**: O(n^2)，不稳定
- **计数排序**: O(n + k)，适合值域有限的整数
- **基数排序**: O(d * (n + k))，从低位到高位依次排序

## A* 寻路算法 (A-Star Pathfinding)

A* 是游戏开发中最常用的启发式寻路算法，综合了 Dijkstra 算法的可靠性（最短路径保证）和贪心最佳优先搜索的效率。

### 核心公式

```
f(n) = g(n) + h(n)
```

- **g(n)**: 从起点到节点 n 的实际代价
- **h(n)**: 从节点 n 到终点的启发式估计代价（启发函数）
- **f(n)**: 通过节点 n 的预估总代价

### 常见启发函数

| 网格类型 | 启发函数 | 公式 |
|----------|----------|------|
| 四方向网格 | 曼哈顿距离 | h = \|x1-x2\| + \|y1-y2\| |
| 八方向网格 | 对角线距离 | h = max(\|x1-x2\|, \|y1-y2\|) |
| 任意方向 | 欧几里得距离 | h = sqrt((x1-x2)^2 + (y1-y2)^2) |

### 步骤

1. 将起点加入 Open List
2. 从 Open List 中取出 f(n) 最小的节点
3. 若该节点是终点，路径找到
4. 将该节点移入 Closed List
5. 处理所有邻居节点，更新 g、h、f 值
6. 重复步骤 2

### Unity 中的实现

- **NavMesh**: Unity 内置导航系统，自动烘焙可行走区域
  - `NavMeshAgent`: 控制寻路代理
  - `NavMeshObstacle`: 动态障碍物（Carve 模式）
  - `OffMeshLink`: 特殊移动链接（跳跃、攀爬）
- **NavMesh 重要参数**:
  - Agent Radius / Height: 代理尺寸
  - Max Slope / Step Height: 最大坡度 / 台阶高度
  - Areas: 区域遮罩，用于区分不同行走代价
  - `agent.remainingDistance <= agent.stoppingDistance` 判断到达

### A* 优化

- ⚠️ 使用二叉堆（Binary Heap）优化 Open List 的查找
- ⚠️ Jump Point Search (JPS) 用于规则的网格地图加速
- ⚠️ 分层寻路 (Hierarchical Pathfinding) 用于大规模地图

## 行为树 (Behavior Tree)

行为树是 AI 行为控制的一种层次化、模块化的方式，广泛用于游戏 AI 开发。

### 节点类型

- **Composite 组合节点**: Selector（优先级选择）、Sequence（顺序执行）、Parallel（并行）
- **Decorator 装饰节点**: 对子节点进行条件过滤、循环、限时等修饰
- **Action 动作节点**: 执行具体行为（移动、攻击、巡逻）
- **Condition 条件节点**: 检测条件（距离、生命值、视野）

### 与 FSM 的对比

| 维度 | 有限状态机 (FSM) | 行为树 (BT) |
|------|----------|------|
| 可读性 | 简单场景好读，复杂时混乱 | 树形结构直观 |
| 复用性 | 状态和转换逻辑需重新设计 | 子树可复用 |
| 扩展性 | 添加状态需重新连接转换 | 添加子树即可 |
| 适用场景 | 简单有限状态 | 复杂 AI 行为 |

## 有限状态机 (FSM)

FSM 由状态 (State)、转换条件 (Transition) 和动作 (Action) 组成。

### 基本结构

```
[Idle] ---检测到敌人---> [Move]
 [^]                        |
  |                         v
  +------失去目标------ [Attack]
```

## Top-K 问题

从一个数据集中找出前 K 个最大（或最小）的元素。

### 常见解法

| 方法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|------|-----------|-----------|---------|
| 全排序后取前 K 个 | O(n log n) | O(1) | K 接近 n |
| 维护大小为 K 的小根堆 | O(n log K) | O(K) | K 远小于 n，最佳方案 |
| 快速选择算法 | O(n) 期望 | O(log n) | K 任意 |
| 计数/桶排序 | O(n) | O(值域) | 值域有限 |

### 堆解法流程

1. 创建一个大小为 K 的小根堆（求 Top-K 大）或大根堆（求 Top-K 小）
2. 遍历所有元素
3. 如果堆未满，直接入堆
4. 如果当前元素大于堆顶（Top-K 大），弹出堆顶，插入当前元素
5. 最终堆中元素即为 Top-K

## 常见算法题速查

### 链表反转

```csharp
ListNode Reverse(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        var next = curr.next; curr.next = prev; prev = curr; curr = next;
    }
    return prev;
}
```

### 两数之和（哈希表 O(n)）

```csharp
int[] TwoSum(int[] nums, int target) {
    var dict = new Dictionary<int, int>();
    for (int i = 0; i < nums.Length; i++) {
        int comp = target - nums[i];
        if (dict.ContainsKey(comp)) return new[] { dict[comp], i };
        dict[nums[i]] = i;
    }
    return null;
}
```

### 二分查找（O(log n)）

```csharp
int BinarySearch(int[] arr, int target) {
    int l = 0, r = arr.Length - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (arr[mid] == target) return mid;
        else if (arr[mid] < target) l = mid + 1;
        else r = mid - 1;
    }
    return -1;
}
```

## 红黑树

一种通过节点颜色和旋转维持平衡的自平衡二叉搜索树，C# 的 `SortedSet<T>` / `SortedDictionary<K,V>` 内部即为红黑树。

### 五条性质

- **根叶黑**：根节点和叶子（NIL）是黑色
- **不红红**：红色节点的父子节点必须为黑色
- **黑路同**：任意节点到其所有后代叶子的路径上黑色节点数相同

### 与 AVL 树的区别

| 维度 | AVL 树 | 红黑树 |
|------|--------|--------|
| 平衡条件 | 严格平衡（高度差 ≤ 1） | 弱平衡（最长路径 ≤ 2 倍最短） |
| 查找 | 更快 | 略慢 |
| 插入/删除 | 旋转次数多 | 最多 3 次旋转 |
| 适用场景 | 读多写少 | 写多读多，综合吞吐更高 |

## A* 核心循环伪代码

```csharp
List<Node> AStar(Node start, Node goal) {
    var openSet = new PriorityQueue<Node>();        // 小根堆，按 fScore 排序
    var closedSet = new HashSet<Node>();
    var gScore = new Dictionary<Node, float>();     // start → n 实际代价
    var fScore = new Dictionary<Node, float>();     // g(n) + h(n) 预估总代价
    var cameFrom = new Dictionary<Node, Node>();    // 路径回溯

    gScore[start] = 0;
    fScore[start] = Heuristic(start, goal);
    openSet.Enqueue(start, fScore[start]);

    while (openSet.Count > 0) {
        var current = openSet.Dequeue();
        if (current == goal) return ReconstructPath(cameFrom, current);

        closedSet.Add(current);
        foreach (var neighbor in GetNeighbors(current)) {
            if (closedSet.Contains(neighbor)) continue;
            float tentativeG = gScore[current] + Cost(current, neighbor);

            if (!gScore.ContainsKey(neighbor) || tentativeG < gScore[neighbor]) {
                cameFrom[neighbor] = current;
                gScore[neighbor] = tentativeG;
                fScore[neighbor] = tentativeG + Heuristic(neighbor, goal);
                if (!openSet.Contains(neighbor))
                    openSet.Enqueue(neighbor, fScore[neighbor]);
            }
        }
    }
    return null; // 无路径
}
```

## 图算法

### Dijkstra（单源最短路径）

每次取距离最小的未访问节点，松弛其邻居。适用于非负权图，O(E log V)。游戏中**非负权边的导航寻路即 Dijkstra**（A* 是加了启发函数的 Dijkstra）。

### 拓扑排序

对 DAG 进行线性排序，使每条边 u→v 中 u 在 v 之前。BFS + 入度表（Kahn 算法）或 DFS 后续遍历实现。场景：**技能树依赖、编译顺序、任务调度**。

## 动态规划

### 0/1 背包问题

n 个物品（重量 w[i]，价值 v[i]），背包容量 W，每件最多选一次，求最大总价值。

**状态转移公式**：

```
dp[i][w] = max(dp[i-1][w], dp[i-1][w - w[i]] + v[i])
```

- 不选第 i 件：`dp[i-1][w]`
- 选第 i 件：`dp[i-1][w - w[i]] + v[i]`（需 w ≥ w[i]）

空间优化为一维数组倒序遍历：O(nW) 时间，O(W) 空间。

### 其他经典 DP

- **LCS（最长公共子序列）**：字符相等时 `dp[i][j] = dp[i-1][j-1] + 1`，否则取 max
- **编辑距离**：插入/删除/替换的最小操作数
- **最长递增子序列**：O(n log n) 贪心 + 二分

## 快速排序

**时间复杂度**: 平均 O(n log n) | 最坏 O(n²)（已有序且选首元素为 pivot）| 空间 O(log n)

**原理**：分治。选 pivot → 分区（左边小于 pivot，右边大于）→ 递归排序左右。

```csharp
void QuickSort(int[] arr, int left, int right) {
    if (left >= right) return;
    int pivot = Partition(arr, left, right);
    QuickSort(arr, left, pivot - 1);
    QuickSort(arr, pivot + 1, right);
}

int Partition(int[] arr, int left, int right) {
    int pivot = arr[right];  // 选最右为基准
    int i = left - 1;        // i 指向小于 pivot 的区域尾部
    for (int j = left; j < right; j++) {
        if (arr[j] < pivot) {
            i++;
            (arr[i], arr[j]) = (arr[j], arr[i]);
        }
    }
    (arr[i + 1], arr[right]) = (arr[right], arr[i + 1]);
    return i + 1;
}
```

**面试要点**：
- 不稳定排序（相等元素可能换位）
- 优化：三数取中法选 pivot 防退化、小数组切换插入排序、尾递归优化
- `Array.Sort()` 内部就是快排+堆排+插入排序的混合

## 打印图形题

**奇数金字塔**（n=3 输出 `13531` / `_131_` / `__1__`）：

```csharp
void PrintPattern(int n) {
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < i; j++) Console.Write(" ");
        int max = 2 * (n - i) - 1;
        for (int k = 1; k <= max; k += 2) Console.Write(k);    // 递增
        for (int k = max - 2; k >= 1; k -= 2) Console.Write(k); // 递减
        Console.WriteLine();
    }
}
```

**核心规律**：第 i 行最大值 `max = 2*(n-i)-1`，先递增奇数到 max，再递减回到 1。

同类题：打印菱形、杨辉三角、打印乘法口诀表 —— 都是**找行号与列数的数学关系**。
