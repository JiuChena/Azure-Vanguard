# CH0221 技能设计（定稿 2026-10-24）

**定位**：有奶的拐力位，**输出较低**。战斗价值 = 治疗 + 全队拐 buff（增伤/暴击/充能效率加速回能）。

### 22102 E `Healing Chord` — 治疗 + 随机拐

**规则**：
1. 治疗**自身 + 全队 HP 最低目标**；治疗量依赖**充能效率**。
2. 随后给全队随机 **三选一** buff（攻击 / 暴伤 / 暴率），持续 10 秒——倍率随技能等级成长（Lv1 20%/10%/5%，每级 +1%/+1%/+0.5%，满级 29%/19%/9.5%）。

**公式**（与 EX 统一基准 = **施法者最大生命**）：

```
治疗量 = 施法者最大生命 × heal% × 充能效率
heal% = 0.15 + (等级-1) × 0.01   （满级 0.24）
```

params：`{heal:0.15:0.01, dur:10:0, atkup:0.20:0.01, critdmg:0.10:0.01, critrate:0.05:0.005}`（全部倍率成长型，满级 heal 24% / atkup 29% / critdmg 19% / critrate 9.5%）

### 22103 Q `Resonance` — 演奏范围拐 + 濒危治疗

**规则**：
1. 演奏 12 秒，以自身为中心扩散律动，**范围内队友** +暴率 +暴伤——随技能等级成长（Lv1 10%/30%，每级 +0.5%/+1%，满级 14.5%/39%）。
2. 队友 HP **跌破 50%** 时，对全部低于 50% 的友方治疗一次；**内置冷却 5 秒**。
3. 需 **80 能量** 充满且 CD（20 秒）转完才可释放。

**公式**：

```
治疗量 = 施法者最大生命 × heal%
heal% = 0.06 + (等级-1) × 0.006   （满级 0.114）
```

params：`{dur:12:0, critrate:0.10:0.005, critdmg:0.30:0.01, threshold:0.5:0, heal:0.06:0.006, energy:80:0}`（critrate/critdmg 成长型，满级 14.5%/39%；heal 满级 11.4%；阈值/时长/能量固定）

### 22104 天赋 `Harmony` — 全队充能效率 + 增伤（被动常驻）

**规则**：在场时全队 +5% 充能效率（固定，回能类）、+10% 伤害加成（随等级成长，每级 +1%，满级 19%）。

params：`{energy:0.05:0, damage:0.10:0.01}`（damage 成长型，满级 19%；充能效率加成属回能类固定 +5%）

> 充能效率抬**全队回能**（见下节）→ 更快攒满 EX 80 能量。与既有口径一致：`CharacterStats.EnergyRecharge`（充能效率，基数 100%，乘区系数），回能 = 回能基数 × 充能效率。
