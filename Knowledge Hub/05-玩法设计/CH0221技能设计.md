# CH0221 技能设计（定稿 2026-10-24）

**定位**：有奶的拐力位，**输出较低**。战斗价值 = 治疗 + 全队拐 buff（增伤/暴击/充能效率加速回能）。

代码位置：技能显示行 `Assets/Module/Unit/Character/Excel/CharacterSkillTable.xlsx`（22102/22103/22104，导出 `ConfigTables/CharacterSkillTable.bytes/.json`）。描述占位符规则见 `SkillDataLibrary.FormatDesc`（`{key}` / `{key:percent}`，percent=数值×100 加 %，缺键加载期报错）。计算侧（`SkillEffectTable` 效果行 + 能量系统实现）**挂账等 BE clip**，本页仅定稿设计与显示侧。

### 22102 E `Healing Chord` — 治疗 + 随机拐

**规则**：
1. 治疗**自身 + 全队 HP 最低目标**；治疗量依赖**充能效率**。
2. 随后给全队随机 **三选一** buff（攻击 / 暴伤 / 暴率），持续 10 秒——倍率随技能等级成长（Lv1 20%/10%/5%，每级 +1%/+1%/+0.5%，满级 29%/19%/9.5%）。

**公式**（与 EX 统一基准 = **施法者最大生命**）：

```
治疗量 = 施法者最大生命 × heal% × 充能效率
heal% = 0.15 + (等级-1) × 0.01   （满级 0.24）
```

params：`{heal:0.15:0.01, dur:10:0, atkup:0.20:0.01, critdmg:0.10:0.01, critrate:0.05:0.005}`（全部倍率成长型，满级 heal 24% / atkup 29% / critdmg 19% / critrate 9.5%）

### 22103 Q `Resonance` — 演奏范围拐 + 濒危治疗

**规则**：
1. 演奏 12 秒，以自身为中心扩散律动，**范围内队友** +暴率 +暴伤——随技能等级成长（Lv1 10%/30%，每级 +0.5%/+1%，满级 14.5%/39%）。
2. 队友 HP **跌破 50%** 时，对全部低于 50% 的友方治疗一次；**内置冷却 5 秒**。
3. 需 **80 能量** 充满且 CD（20 秒）转完才可释放。

**公式**：

```
治疗量 = 施法者最大生命 × heal%
heal% = 0.06 + (等级-1) × 0.006   （满级 0.114）
```

params：`{dur:12:0, critrate:0.10:0.005, critdmg:0.30:0.01, threshold:0.5:0, heal:0.06:0.006, energy:80:0}`（critrate/critdmg 成长型，满级 14.5%/39%；heal 满级 11.4%；阈值/时长/能量固定）

### 22104 天赋 `Harmony` — 全队充能效率 + 增伤（光环）

**规则**：在场时全队（含自己）+5% 充能效率（固定，回能类）、+10% 伤害加成（随天赋技能等级每级 +1%，满级 19%）。

params：`{energy:0.05:0, damage:0.10:0.01}`（damage 成长型，满级 19%；充能效率加成属回能类固定 +5%）

> 充能效率抬**全队回能**（见下节）→ 更快攒满 EX 80 能量。与既有口径一致：`CharacterStats.EnergyRecharge`（充能效率，基数 100%，乘区系数），回能 = 回能基数 × 充能效率。

**实现（2026-11-04）**：注册为全场 Effect `HarmonyTalentEffect`（`TalentEffectContainer`）；`CanAcquire` = 友方且来源存活；获取者由 `TalentAura` 汇总加成（`EnergyManager` / `BattleDamage` 读取）；Effect 页展示 buff id `2210401`；CH0221 倒地释放、复活重新提供。**面板展示**：实现 `ITalentDisplayStats`，视图就绪时给单位 `StatRuntimeData` 挂 `EnergyRecharge +0.05` / `DamageBonus +damage`（source=`talent_CH0221_22104`），释放时按来源撤——角色面板 final 数值/高亮正确；战斗结算仍走 `TalentAura`，避免双算。

### 22111 追奏（天赋节点）— 全队隐形 Effect

**解锁**：`UnlockNodeTable` 22111 解锁后启用（`CharacterTable.talentIds = 22111`）；22112 舞台精神已删除。

**规则**：给全队（含 CH0221）施加隐形【追奏】Effect；持有者对敌人造成伤害时，每次伤害独立 30% 概率追加一次追奏伤害。

**公式**：`基础值 = CH0221 最终最大生命 × 充能效率 × 5%`；暴击率/暴伤/伤害加成全部取 CH0221 面板；**不减目标防御**；击杀归属与击杀回能算给实际造成伤害的持有者；追奏伤害不再触发追奏（Kind=FollowUp 防递归）。

**参数**：节点 params `{chance:0.3:0, ratio:0.05:0}`；Effect 页展示 buff id `2211101`。

**实现**：`Talents_CH0221` 注册 `EncoreTalentEffect`；`BattleDamage.Apply` 统一伤害入口广播 `DamageDealt`，容器派发给攻击者已获取的效果；普攻伤害由 `PooledSpawnExecuteSO.hitEffect`（挂 `CH0221_NormalAttack`）在子弹命中回调结算。

**触发流程（2026-11-04/05 用户拍板）**：CH0221 进场 → 表现桥在 Behavior 就绪后置 `BattleUnitState.WantTalent` → HSM `CombatTalentState` 进入并播放 `Talent` BE clip（1.5s，Once）→ clip EventTrack t=0 的 `CH0221_Talent.asset`（`EffectMethodExecuteSO`，effectKey=`TalentApply`）→ `ApplyTalent` → `Talents_CH0221.Register` 把 Harmony/追奏注册进全场 Effect 容器。**Talent 播放期间 Attack/Skill/Move 均不可打断**（无出边），播完才回 Idle/Move；容器本身不自动注册。
