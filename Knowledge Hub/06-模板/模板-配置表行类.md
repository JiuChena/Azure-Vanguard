# 模板-配置表行类

> 新配置表的 C# 行类骨架。管线操作见 [[02-流程SOP/SOP-数据表流水线]]；新加物品见 [[02-流程SOP/SOP-新加物品与配表]]。先例：`Core/Gameplay/Item/ItemRow.cs`、`Core/Gameplay/Unit/CharacterRow.cs`、`TrinketRow.cs`。

## 行类骨架（map 格式，列名匹配）

```csharp
using MessagePack;

namespace Framework.Gameplay.MyModule   // Core 层：挂 Framework.* 命名空间
{
    /// <summary>
    /// MyTable 行。Excel：<表名>（列：id,name,value,tags）。
    /// </summary>
    [MessagePackObject]
    public class MyRow : IConfigTableRow<string>   // TKey = 主键类型
    {
        [Key("id")]
        public string id { get; set; }

        [Key("name")]
        public string name { get; set; }

        [Key("value")]
        public int value { get; set; }

        [Key("tags")]
        public string tags { get; set; }

        /// <summary>主键（[IgnoreMember]，不序列化）。</summary>
        [IgnoreMember]
        public string PrimaryKey => id;

        /// <summary>派生属性标 [IgnoreMember]。</summary>
        [IgnoreMember]
        public string[] TagList =>
            string.IsNullOrEmpty(tags) ? Array.Empty<string>() : tags.Split(',');
    }
}
```

## 硬规则

1. **[MessagePackObject] 类型所有 public 成员必须标 [Key("列名")] 或 [IgnoreMember]**——漏标反序列化直接抛异常（ItemRow.PrimaryKey 曾踩）
2. **[Key("列名")] 与 xlsx 第 1 行字段名逐字一致**（map 格式按列名匹配，不按位置）
3. **加列不破坏契约**：Excel 加列而行类没加字段 → 反序列化忽略该 key；行类加字段而 Excel 没有 → 反序列化为默认值
4. 派生属性（PrimaryKey/TagList）一律 `[IgnoreMember]`
5. 字段名与列名同名（小写），列对齐 xlsx
6. 解析列（逗号分隔 tags、`itemId:count`、`key:value;…`）用统一容错解析（碎片/坏浮点/多余冒号全滤除）——先例 `ItemCost` / `EnsembleRow.GetBonus`

## Excel 侧约定

- 第 1 行字段名（`#` 开头=注释列不导出）；第 2 行类型 `int/long/float/bool/string`（可空格追加中文注释）；第 3 行起数据
- 每个页签一张表；**第 1 列即主键**（允许语义化命名：skillId/effectId/nodeId/breakStage/level）
- 引用列/标签列逗号分隔（`usable,sell`、`22101,22102`）；消耗列 `itemId:count` 逗号分隔多段

## 信封（一般不用动）

`ConfigTableFile<TRow>` 信封已泛型化（`{version, tableName, rows}`）。**勿用 `Dictionary<string,object>` 自造信封**——动态格式化器反射字段序列化两端对不上（已踩）。
