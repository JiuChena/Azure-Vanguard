# 原型验收标准

> 本文档为**第二版**玩法设计稿（2026-09-10 RTS×TD 融合改版）。验收对象是**未来的可玩原型**，不是文档本身；原型完成时逐项勾验。

## 可玩性验收

- [ ] 能完成 6 人编队、选择 ≤3 类携带道具并进入关卡。
- [ ] 场内点数按基准速率回复，部署/复活/建造正确扣费，点数不足时对应入口置灰。
- [ ] 部署流程完整（点头像 → 选层级部署位 → 确认扣点），不可部署位正确置灰，干员不可跨层部署。
- [ ] 自动模式生效：至少重装/穿透/后援 3 个职业的 AI 选位符合 [[01-核心战斗系统]] 职业 AI 战略机制表（重装守要道、穿透覆盖主路、后援贴战线）。
- [ ] 手动模式生效：指定常驻点位后干员移动并驻守不动；按角色独立切换自动/手动随时生效。
- [ ] 阻挡生效：下沉区内重装与掩体墙按阻挡名额拦截敌人，交战互殴正常；掩体墙被摧毁后敌人恢复行进。
- [ ] 上层安全规则：地面敌人不攻击上层干员；浮炮/电水母与 Boss 范围技能可及上层。
- [ ] 复活生效：点数复活正确扣费并重选部署位；自动复活倒计时正确（受倍速影响），二者互斥。
- [ ] 场内经验生效：击杀/治疗/助攻正确累计经验，升级提升伤害，局内:局外 = 3:7 公式与全局系数一致，跨场清零。
- [ ] 道具建造生效：4 类道具可购买放置于建造位，效果（阻挡/攻击/治疗/Buff）与价格正确，同种同场上限生效。
- [ ] 技能可积攒/释放，三类触发（攻击回复/受击回复/自动回复）各至少一名干员验证通过。
- [ ] 倍速 1x/2x 生效；暂停冻结全部战斗逻辑，暂停中可下达指令且恢复后立即执行。
- [ ] 漏怪扣生命点数，归零失败；波次清空胜利。
- [ ] 能通关 T1 教学关（含教学引导，可跳过）。

## 内容验收

- [ ] 14 名干员数据齐全（6 职业覆盖，层级/AI 战略机制/复活参数字段与 [[01-核心战斗系统]] 数值骨架一致）。
- [ ] 7 类敌人模板齐全（含经验值字段）；4 类场内道具齐全（≥2 种掩体墙）。
- [ ] 3 个完整关（T1/N1/B1）+ 2 个概要关（E1/E2）。
- [ ] T1/N1/B1 波次表可被 01 规则完整解释（点数回复量 vs 部署/建造需求、阻挡容量 vs 敌人密度、经验曲线 vs 场内成长预期校验通过）。

## 技术验收

- [ ] [[05-原型技术映射]] 每个"需新增/需扩展"项有明确方案，或已列入开放问题清单。
- [ ] 零框架代码改动（Gear/GAS/BetterHSM/BehaviorEditor 只读）。
- [ ] 资源走 Lease/Scope，波次敌人生成与道具建筑走对象池，无资源泄漏（对照 `Knowledge Hub/modules/Gear 基础模块.md` 使用检查表）。
