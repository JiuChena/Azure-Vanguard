# 原型验收标准

> 本文档为第一版玩法设计稿。验收对象是**未来的可玩原型**，不是文档本身；原型完成时逐项勾验。

## 可玩性验收

- [ ] 能完成 8 人编队并进入关卡。
- [ ] DP 按基准速率回复，部署正确扣费，DP 不足时卡片置灰。
- [ ] 部署流程完整（选卡 → 选格 → 朝向 → 确认），不可部署格正确置灰。
- [ ] 阻挡生效：被阻挡敌人停下交战，阻挡数上限正确。
- [ ] 索敌符合规则（阻挡优先 → 路径进度优先）。
- [ ] 技能可积攒/释放，三类触发（攻击回复/受击回复/自动回复）各至少一名干员验证通过。
- [ ] 撤退返还 50% 费用并进入再部署冷却，冷却计时正确（受倍速影响）。
- [ ] 倍速 1x/2x 生效；暂停冻结全部战斗逻辑且禁止部署/撤退/技能。
- [ ] 漏怪扣生命点数，归零失败；波次清空胜利。
- [ ] 能通关 T1 教学关（含教学引导，可跳过）。

## 内容验收

- [ ] 14 名干员数据齐全（6 职业覆盖，字段与 [[01-核心战斗系统]] 数值骨架一致）。
- [ ] 7 类敌人模板齐全；3 个完整关（T1/N1/B1）+ 2 个概要关（E1/E2）。
- [ ] T1/N1/B1 波次表可被 01 规则完整解释（DP 回复量 vs 部署需求、阻挡数 vs 敌人密度校验通过）。

## 技术验收

- [ ] [[05-原型技术映射]] 每个"需新增/需扩展"项有明确方案，或已列入开放问题清单。
- [ ] 零框架代码改动（Gear/GAS/BetterHSM/BehaviorEditor 只读）。
- [ ] 资源走 Lease/Scope，波次敌人生成走对象池，无资源泄漏（对照 `Knowledge Hub/modules/Gear 基础模块.md` 使用检查表）。
