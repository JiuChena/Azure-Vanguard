# 核心战斗系统

> 本文档为**第二版**玩法设计稿（2026-09-10 即时战略×塔防融合改版），描述目标设计而非当前代码现状（遵循知识库文档规则）。术语以 [[00-策划案总览]] 术语表为准。

## 设计目标与边界

- 自研"RTS×TD 融合"玩法：敌人侧保留塔防的波次编排与路径推进；干员侧引入即时战略的自主选位移动与玩家驻守指令。
- 2026-09-10 起**不再以明日方舟为复刻蓝本**；旧版"DP-部署位-阻挡互殴-再部署"复刻规则整体废弃，改版决定记录于 [[00-策划案总览]]。
- 本文档只定义规则与数值骨架，不涉及实现方案（实现映射见 [[05-原型技术映射]]）。

## 战斗流程

```text
准备阶段 → 部署运营阶段 → 结算
编队6人     点数回复/部署/复活/
携带道具    建造道具/AI选位或驻守
```

- **准备阶段**：从已解锁干员中选 6 人编队，并从道具库中选择携带的场内道具（种类上限见道具系统）；查看关卡信息（地图缩略、敌人类型、初始点数）。
- **部署运营阶段**：战斗实时进行，玩家通过部署、复活、建造道具与切换干员模式应对波次。
- **结算阶段**：见胜负条件。

## 战场结构与上下层

- 战场为 3D 场景，分**上层**与**下沉区**两层，**上下层不互通**。
- **上层**：安全平台。输出/辅助职业（穿透/轻装/突击/后援/协同）只能部署于上层；地面敌人无法接触上层干员（远程敌人在射程内可攻击，Boss 范围技能除外）。
- **下沉区**：敌人唯一活动层。敌人以 NavMesh 在下沉区内沿预定义路径行进；仅重装干员可部署于下沉区；掩体墙与功能桩放置于此。
- 全场以 2m×2m 网格表达可放置点位：
  - **部署位**：分上层位（输出/辅助）与下层位（重装专用），同一位置同一时间只能一个干员。
  - **建造位**：道具专用点位，与部署位分开标记，同一位置同一时间只能一个道具。
- **朝向概念取消**：干员攻击范围为以自身为圆心的半径/扇形描述，不依赖部署朝向。

## 场内点数

| 项 | 基准值 | 说明 |
| --- | --- | --- |
| 初始点数 | 每关配置（教学 20 / 标准 20 / Boss 25） | 开局即有 |
| 自然回复 | 2 点/秒 | 关卡可配 0.5-2.0 倍系数 |
| 点数上限 | 99 | 超出不累积 |
| 用途 | 初次部署 / 复活 / 道具购买放置 | 三者共用，构成核心资源决策 |

## 干员部署

- 单局编队 6 名干员，全部可上场部署，**不得追加**（编队即全部战力）。
- 部署消耗该干员的**部署点数**，点数不足时头像置灰不可选。
- 部署动作：点选干员头像 → 高亮其层级可部署位 → 点选目标位确认扣点 → 落地 0.5s 后可行动（原型不做部署硬直判定）。
- 部署完成后干员默认进入**自动模式**。

## 常驻点位与自动/手动模式

每名在场干员始终拥有一个**常驻点位**（当前驻守的目标位置），并按自身模式行动：

- **自动模式**（默认）：干员按本职业的 **AI 战略机制**（见下表）自行选择并动态调整常驻点位；移动至点位后按索敌规则作战。
- **手动模式**：玩家为干员指定常驻点位，干员移动至该点后驻守不动（仅范围内索敌攻击），直到再次被指定点位或切回自动模式。
- **粒度**：按角色独立切换（部分托管、部分手操），随时生效；移动途中切换立即按新规则重选点位。
- 干员移动**不跨层**。
- 同一常驻点位可被多名单位共享（点位非独占，独占的是部署位）。

### 职业 AI 战略机制（自动模式选位逻辑）

| 职业 | 自动选位策略 |
| --- | --- |
| 重装 | 驻守下沉区路径要道：选阻挡价值最高的下层位（路径瓶颈、敌人流量最大处）；生命低于 30% 时向最近的受保护下层位后撤【待确认：后撤规则细节】 |
| 穿透 | 上层选位最大化对主路径的覆盖与灌伤机会：优先覆盖精英/Boss 途经路段 |
| 轻装 | 上层选位覆盖敌人流量最大的路径段，稳定清杂 |
| 突击 | 上层游走：常规驻守能覆盖当前主战场的位置；大招就绪时向敌人密集段对应的上层位移动，放大爆发收益 |
| 后援 | 治疗覆盖最大化：驻点使范围内友方总缺血量/覆盖人数最大，优先贴近承伤最重的战线 |
| 协同 | 跟随场上伤害贡献最高的友方输出，驻守能覆盖其目标的位置 |

> AI 选位是本版玩法与技术的核心风险项，原型以"规则化打分"实现（对候选点位按职业权重评分），不做学习型 AI。

## 阻挡与交战

- **阻挡**：下沉区内，敌人行进路径上接触**阻挡名额未满的重装干员或掩体墙**时停下进入交战，双方按各自攻击间隔互殴。上层干员与桩类道具不参与阻挡。
- 阻挡上限：重装 = 干员表阻挡数；掩体墙 = 道具定义值。
- 掩体墙被摧毁后，其阻挡中的敌人立即恢复行进。
- **索敌**（干员攻击目标选择）：
  1. 优先攻击自己阻挡的敌人（仅重装）；
  2. 否则攻击攻击范围内"沿路径离防线终点最近"的敌人；
  3. 后援改为治疗索敌：范围内缺血比例最高的友方。
- 远程敌人（浮炮/电水母）在射程内站定攻击最近可攻击目标（含上层干员与建筑）。

## 阵亡与复活

- 干员生命归零即**阵亡**，从场上移除，常驻点位释放。
- 复活两途径（互斥，点数复活后自动复活计时取消）：
  1. **点数复活**：消耗该干员的**复活点数**（基准 = 部署点数 × 1.5【待确认】），玩家点选其在原层级任一部署位重新部署。
  2. **自动复活**：不消耗点数，阵亡后倒计时（基准 30s【待确认】，干员表可覆盖，如潜航 10s）到时在原常驻点位复活。
- 原型不设主动撤回机制（点数复活已承担原"撤退运营"职能）【待确认：是否保留"召回返还部分点数"】。

## 场内经验成长

干员在单局内通过以下行为获得**场内经验**（每场战斗开始时归零）：

| 来源 | 规则 |
| --- | --- |
| 击杀 | 击杀敌人获得其经验值（敌人模板定义，见 [[03-关卡与敌人]]） |
| 治疗 | 每累计治疗 500 点折算 1 次标准击杀经验【待确认：折算值】 |
| 助攻 | 被自身增益（Buff）的友方完成击杀时，获得该击杀 30% 经验 |

- 场内等级 1-10【待确认】，升级所需经验递增；升级**只提升伤害**，不改变其他面板与技能结构。
- **局内:局外 = 3:7**：

```text
最终伤害 = 基础伤害 × (1 + 0.7 × 局外成长系数 + 0.3 × 局内成长系数)
局外成长系数：由干员等级（1-60）与技能等级（1-7）推导，归一化 0-1（满级满技能 = 1）
局内成长系数 = 当前场内等级 ÷ 场内满级（0-1）
```

- 即全部伤害成长中，局外养成占 70%、场内表现占 30%；场内满级约相当于局外养成收益的 3/7。
- 0.7/0.3 为全局配置系数，实际调参时按关卡体验调控。

## 道具系统

战前从道具库选择携带（**种类上限 3**），战斗中用场内点数购买并放置于建造位；同一道具同场存在上限 2 个【待确认】。

| 道具 | 类别 | 价格 | 生命 | 效果 |
| --- | --- | --- | --- | --- |
| 标准掩体墙 | 掩体墙 | 8 | 2000 | 阻挡 2；仅放置下沉区 |
| 重型掩体墙 | 掩体墙 | 14 | 5000 | 阻挡 3；仅放置下沉区 |
| 哨戒炮塔 | 防御塔 | 20 | 1500 | 每 1.5s 对射程内（4 格）最近敌人造成 200 物理伤害 |
| 回血桩 | 功能桩 | 15 | 1000 | 每 1s 治疗范围内（半径 2 格）友方 60 点 |
| 强攻桩 | 功能桩 | 15 | 1000 | 光环：范围内（半径 2 格）友方攻击 +20% |

- 掩体墙仅放下沉区；哨戒炮塔与功能桩可放上层或下沉区建造位。
- 敌人索敌**不主动攻击**桩塔与未阻挡它的掩体墙；掩体墙在被阻挡交战时被攻击，桩塔仅被远程敌人与范围技能波及【待确认】。

## 职业模板

### 职业定位（6 职业体系）

> 2026-09-10 改版：职业定位描述沿用 6 职业体系，新增层级与阻挡归属。

| 职业 | 层级 | 定位描述 |
| --- | --- | --- |
| 穿透 | 上层 | 攻速慢、伤害高，高爆发高灌伤输出位；攻击距离较远；自身脆弱，依赖暴击，输出曲线不稳定；不适合应对大量血量不坚的敌人。 |
| 轻装 | 上层 | 攻速快、单发伤害低，伤害曲线平缓稳定，主力输出之一。**改版说明：由旧版近战模板调整为上层远程速射**。 |
| 重装 | 下沉区 | 唯一可进入下沉区的地面职业；血厚、承担阻挡抗线，带少量回血与控制技能；伤害低，不属于主力输出。 |
| 突击 | 上层 | 依赖大招进行突然集中式爆发的副 C；有少量拐力（自拐 + 少量群拐）；普通攻击表现平平，整体输出不如主力 DPS。 |
| 后援 | 上层 | 群体奶 + 群体拐力；输出量极少，主要职责是回血和加 Buff。 |
| 协同 | 上层 | 群体拐 / 单体拐；个别角色大招可能是爆发输出技能，但仍以辅助上 Buff 为主。 |

- 原型无飞行单位，"对空"属性仅作模板预留不启用。
- 法术伤害无视防御、按法抗减免；物理伤害按防御减免；减免公式沿用分段减伤骨架【待确认：具体公式】。
- 旧版"部署模板【待确认】"由层级列 + 职业 AI 战略机制表替代。

## 技能系统

- 每名干员 1 个技能（原型不做天赋/被动；模板级特性在干员表单独标注）。
- **SP 触发类型**：
  - 攻击回复：每次攻击 +1 SP；
  - 受击回复：每次被攻击 +1 SP；
  - 自动回复：每秒 +1 SP。
- **释放方式**：手动触发（点击释放）或自动触发（SP 满自动释放），由技能定义。
- **技能循环**：初始 SP → 积攒 → 触发 → 持续时间（面板/行为按技能描述改变）→ 结算 → 重新积攒。
- 技能等级 1-7 级，数值线性提升（见 [[02-干员与养成]]）。

## 倍速与暂停

- **倍速**：1x / 2x 全局切换，随时生效。
- **暂停**：冻结全部战斗逻辑（点数回复、SP 积攒、移动、攻击、冷却计时、倒计时）；暂停时**允许下达指令**（指定常驻点位、部署、复活、建造道具），指令在恢复后立即执行【待确认：RTS 惯例的暂停指挥 vs 旧版仅查看】。

## 胜负条件

- **生命点数**：每关配置（教学 5 / 标准 3 / Boss 3）。
- 敌人抵达防线终点：扣 1 点。
- 生命点数归零 → **失败**（可重试）；全部波次出完且场上无存活敌人 → **胜利**。

## 战斗界面与交互

移动端横屏 HUD 布局：

```text
┌──────────────────────────────────────────────┐
│ 生命点数♥3   W2/5                 [2x] [⏸] │
│                                              │
│        （3D 战场：上层 / 下沉区）             │
│                                              │
│ [头像×6：血条|模式徽标]    道具栏[■][■][■]   │
│ 点数 32/99 ▓▓▓░░      [部署] [复活] [建造]   │
└──────────────────────────────────────────────┘
```

- **部署流程**：点选干员头像 → 高亮其层级部署位 → 点选确认扣点；任意步骤可取消。
- **指定常驻点位**：点选场上干员 → 点选目标点位 → 干员移动过去驻守（等同切入手动模式）。
- **模式切换**：点选干员信息条上的自动/手动开关。
- **复活流程**：阵亡干员头像亮起 → 点选立即复活（扣复活点数，选部署位），或等待自动复活。
- **建造流程**：点选道具栏道具 → 高亮建造位 → 确认扣点放置。
- **范围预览**：部署/建造模式与点选单位时，显示攻击/效果范围覆盖。
