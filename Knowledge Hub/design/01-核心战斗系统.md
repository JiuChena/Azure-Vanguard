# 核心战斗系统

> 本文档为第一版玩法设计稿，描述目标设计而非当前代码现状（遵循知识库文档规则）。术语以 [[00-策划案总览]] 术语表为准。

## 设计目标与边界

- **忠实复刻**明日方舟核心战斗规则；机制描述以明日方舟公开资料为准，与原作保持一致，不确定处标注【待确认】。
- **微创新**仅限题材包装、3D 表现、关卡机关三个层面（见文末微创新边界）。
- 本文档只定义规则与数值骨架，不涉及实现方案（实现映射见 [[05-原型技术映射]]）。

## 战斗流程

```text
准备阶段 → 部署运营阶段 → 结算
编队8人     DP回复/部署/      胜利/失败
            技能/撤退再部署
```

- **准备阶段**：从已解锁干员中选 8 人编队，查看关卡信息（地图缩略、敌人类型、初始资源）。
- **部署运营阶段**：战斗实时进行，玩家通过部署、撤退、再部署与技能释放应对波次。
- **结算阶段**：见胜负条件。

## 地图与格子系统

- 战场为 3D 场景内的平面网格，首版 **10×6**，格子尺寸 2m×2m。
- 部署位分两类：
  - **地面位**：干员可被近战敌人接触攻击。
  - **高台位**：抬高 1.5m，地面敌人无法接触；原型中敌人不攻击高台位干员（Boss 范围技能除外）。
- **朝向**：部署时从四个方向中选择朝向，决定攻击范围覆盖；部署后不可转向，只能撤退重铺。
- 同一部署位同一时间只能有一个干员。

## 费用系统（DP）

| 项 | 基准值 | 说明 |
| --- | --- | --- |
| 初始 DP | 每关配置（教学 10 / 标准 10 / Boss 15） | 开局即有 |
| 自然回复 | 1 DP/秒 | 关卡可配 0.5-2.0 倍系数 |
| DP 上限 | 99 | 超出不累积 |
| 技能回复 | 职业技能产 DP（6 职业体系回费手段【待确认】） | 回费核心手段 |

## 部署规则

- 部署消耗该干员的费用值，从当前 DP 扣除；DP 不足时卡片置灰不可选。
- 同时在场干员数 ≤ 关卡部署位数（8-9 个）。
- 部署动作：落地后 0.5s 即可行动（原型不做部署硬直判定）。

## 阻挡与索敌

- **阻挡**：敌人行进至干员所在格相邻路径时，若干员阻挡数未满，敌人停下进入交战；交战中双方按各自攻击间隔互殴。
- **索敌**（干员攻击目标选择）：
  1. 优先攻击自己阻挡的敌人；
  2. 否则攻击攻击范围内"沿路径离防线终点最近"的敌人【待确认：与明日方舟默认索敌优先级核对】。
- 后援索敌：攻击范围内生命最低的友方干员。

## 职业模板

### 职业定位（当前设计方向：6 职业体系）

> 2026-09-10 更新：职业体系确定为以下 6 职业定位（穿透 / 轻装 / 重装 / 突击 / 后援 / 协同）。

| 职业 | 定位描述 |
| --- | --- |
| 穿透 | 攻速慢、伤害高，高爆发高灌伤输出位；攻击距离普遍较远；自身较为脆弱，容易阵亡。比较依赖暴击，输出曲线不稳定——没有暴击时短时间内很难再大量灌伤；不适合应对大量血量不坚的敌人。 |
| 轻装 | 攻速快、单发伤害低，伤害曲线平缓稳定，也属于主力输出（与穿透的爆发集中、依赖暴击、曲线不稳定形成对比）。 |
| 重装 | 前排抵挡敌人的位置；血量厚，自身拥有少量回血的回复技能，可能带有一定的控制技能；伤害较低，不属于主力输出，主要职责是阻挡敌人前进节奏。 |
| 突击 | 依赖大招进行突然集中式爆发的副 C；不可作为主力输出。有少量拐力（自拐 + 少量群拐）；大招倍率较高，但普通攻击与其他方面表现平平，整体输出水平不如主力输出 DPS。 |
| 后援 | 群体奶 + 群体拐力位置；输出量极少，自身血量一般不如前排，主要职责是回血和加 Buff。 |
| 协同 | 群体拐 / 单体拐位置；个别角色大招可能是爆发输出技能而非主要上 Buff 技能（上拐力较少），但该位置仍以辅助位上 Buff 为主。 |

- 部署模板（部署位 / 典型阻挡 / 攻击范围 / DP 交互）尚未随 6 职业体系重排【待确认：除重装（地面位、阻挡 3）外待定义】。

- 原型无飞行单位，"对空"属性仅作模板预留不启用【待确认：后续引入飞行单位时启用】。
- 法术伤害无视防御、按法抗减免；物理伤害按防御减免；减免公式采用明日方舟式分段减伤【待确认：具体公式以公开资料核对后固化】。

## 技能系统

- 每名干员 1 个技能（原型不做天赋/被动；模板级特性在干员表单独标注）。
- **SP 触发类型**：
  - 攻击回复：每次攻击 +1 SP；
  - 受击回复：每次被攻击 +1 SP；
  - 自动回复：每秒 +1 SP。
- **释放方式**：手动触发（点击释放）或自动触发（SP 满自动释放），由技能定义。
- **技能循环**：初始 SP → 积攒 → 触发 → 持续时间（面板/行为按技能描述改变）→ 结算 → 重新积攒。
- 技能等级 1-7 级，数值线性提升（见 [[02-干员与养成]]）。

## 再部署与撤退

- **撤退**：主动收回场上干员，返还已消耗费用的 **50%**（向下取整），进入再部署冷却。
- **阵亡**：生命归零视同撤退，但不返还 DP，进入再部署冷却。
- **再部署时间**（从撤退/阵亡瞬间开始，按游戏时间计时，受倍速影响）：常规 70s（基准值，干员表可覆盖；按职业的再部署分类【待确认】）。

## 倍速与暂停

- **倍速**：1x / 2x 全局切换，随时生效。
- **暂停**：冻结全部战斗逻辑（DP 回复、SP 积攒、移动、攻击、冷却计时），仅允许查看面板/攻击范围/波次信息；**不可**部署、撤退、释放技能【待确认：与明日方舟暂停规则核对】。

## 胜负条件

- **生命点数**：每关配置（教学 5 / 标准 3 / Boss 3）。
- 敌人抵达防线终点：扣 1 点。
- 生命点数归零 → **失败**（可重试）；全部波次出完且场上无存活敌人 → **胜利**。

## 战斗界面与交互

移动端横屏 HUD 布局：

```text
┌──────────────────────────────────────────────┐
│ 生命点数♥3   W2/5                 [2x] [⏸] │
│                                              │
│              （3D 战场区域）                  │
│                                              │
│ DP 12/99 ▓▓▓░░              [卡][卡][卡]... │
└──────────────────────────────────────────────┘
```

- **部署流程**：点选卡片 → 进入部署模式（可部署格高亮、不可部署格置灰）→ 点选目标格 → 四向轮盘选朝向 → 确认扣费部署；任意步骤可取消。
- **撤退流程**：点选场上干员 → 弹出信息条（面板/技能/撤退）→ 撤退确认。
- **技能释放**：SP 满时干员头顶亮技能图标，点击释放；自动触发技能自动释放。
- **范围预览**：部署模式与点选干员时，显示攻击范围覆盖格。
