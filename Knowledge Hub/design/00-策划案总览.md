# 策划案总览

> 本模块为第一版玩法策划案（设计稿）：描述目标设计而非当前代码现状（遵循知识库文档规则）。

## 项目定位

Azure Vanguard（蔚蓝先锋）是一款**明日方舟式的 3D 塔防战略游戏**。玩家扮演海上先锋舰队的指挥官，在 3D 立体战场上部署"干员"，利用阻挡、职业配合与技能循环，阻止敌人抵达防线终点。

当前阶段定位：**玩法原型优先**。第一版策划案聚焦核心战斗循环与精简养成，验证"部署—阻挡—费用管理—技能循环"的核心乐趣；抽卡、基建、剧情等长线系统只做框架级预留（见 [[04-外围系统预留]]）。

## 设计支柱

1. **忠实复刻核心循环。** 部署费用（DP）、阻挡数、职业模板、技能触发、再部署与撤退、倍速与暂停等核心规则与明日方舟保持一致，不擅自改动。复刻机制以明日方舟公开资料为准，不确定处标注"待确认"。
2. **3D 卡通表现。** 角色与场景采用 3D 卡通渲染，复用项目现有卡通 Shader 工具链与 GAS/BehaviorEditor 行为工具链；战场为 3D 场景内的方格布防，表现升级但规则不变。
3. **微创新限界。** 差异化只允许出现在三个层面：题材包装（近未来海洋）、3D 场景表现（高低差视野等）、关卡机关（地形类机关）。核心战斗规则冻结，详见 [[01-核心战斗系统]] 的微创新边界章节。

## 核心循环

```text
┌────────────┐    ┌────────────┐    ┌────────────┐
│  编队准备   │ →  │  战斗部署   │ →  │  波次防御   │
│ 选择8名干员 │    │ 消耗DP放置  │    │ 阻挡/输出/  │
└────────────┘    │ 调整朝向    │    │ 技能循环    │
                  └────────────┘    └─────┬──────┘
                        ↑                 │ 漏怪扣生命点
                  ┌───────┴───────┐       ↓
                  │  结算与养成    │ ← ┌────────────┐
                  │ 材料/信用/经验 │   │ 胜利/失败   │
                  └───────────────┘   └────────────┘
```

单局内循环：DP 随时间回复 → 部署干员占位 → 干员阻挡并输出 → 技能积攒与释放 → 撤退/再部署调整阵型 → 抵御全部波次。

局外循环：通关获得养成资源 → 干员升级变强 → 挑战更高难度关卡。

## 3D 表现方向

- **战场**：3D 场景中的平面网格（首版 10×6），网格分"地面位"与"高台位"两类，高台位有可读的高度差与视野表现。
- **角色**：3D 卡通渲染角色（复用 `Assets/Editor/Shader/` 卡通 Shader 工具链），战斗中待机/攻击/技能由 BehaviorEditor 时间轴驱动。
- **镜头**：固定俯视角（可微调俯仰），战斗中允许拖拽平移与缩放，不做自由旋转（降低 3D 化的操作与表现成本）。
- **表现升级点**：高低差带来的射程遮挡表现、技能的立体特效、Boss 登场的运镜。均为表现层，不影响规则数值。

## 原型目标

| 维度 | 目标 |
| --- | --- |
| 职业 | 6 职业定位体系全部定义（穿透/轻装/重装/突击/后援/协同，见 [[01-核心战斗系统]]）；部署模板待重排【待确认】 |
| 干员 | 14 名原型干员（6 职业覆盖：轻装 4 / 穿透 4 / 重装 2 / 后援 2 / 协同 1 / 突击 1） |
| 关卡 | 3 个完整规格关卡（教学/标准/Boss）+ 2 个扩展关概要 |
| 敌人 | 7 类敌人模板（普通近战/远程/重甲/快速/法术/精英/Boss） |
| 养成 | 纯等级 1-60 + 技能等级 1-7，不做精英化/潜能/专精 |
| 外围 | 全部占位，不进入原型 |

## 术语表

后续所有策划案文档必须使用以下术语，不得使用同义异名。

| 术语 | 定义 |
| --- | --- |
| 干员 | 玩家可部署的战斗单位。 |
| 部署位 | 地图上可放置干员的格子，分**地面位**（可被敌人接触）与**高台位**（不可被地面敌人接触）。 |
| DP（部署费用） | 部署干员消耗的资源，随时间自然回复，部分职业技能可额外回复（6 职业体系回费手段【待确认】）。 |
| 阻挡数 | 干员可同时阻挡的敌人数上限；被阻挡的敌人停下并与干员互殴。 |
| 索敌 | 干员在攻击范围内选择攻击目标的规则。 |
| 技能循环 | 技能点（SP）积攒 → 触发 → 持续 → 结算的完整周期。 |
| SP | 技能点，按触发类型（攻击回复/受击回复/自动回复）积攒。 |
| 拐 / 拐力 | 为友方提供增益（Buff）的支援能力俗称；上拐即施加增益。 |
| 灌伤 | 在短时间内向目标集中倾泻大量伤害。 |
| 副 C | 副输出位，输出能力低于主力输出（DPS）。 |
| 再部署 | 干员撤退或阵亡后，等待冷却时间后重新部署。 |
| 撤退 | 主动收回干员，返还部分已消耗 DP，并进入再部署冷却。 |
| 波次 | 关卡内一批敌人的出怪编排单位（W1、W2……）。 |
| 生命点数 | 关卡防御资源，敌人抵达终点扣减，归零即失败。 |
| 理智 | （外围占位）进入关卡的体力消耗，原型不实现。 |
