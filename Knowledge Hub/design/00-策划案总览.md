# 策划案总览

> 本模块为**第二版**玩法策划案（设计稿）：2026-09-10 由"明日方舟式塔防"改版为"即时战略×塔防融合"方向，旧版可经 git 历史回溯。描述目标设计而非当前代码现状（遵循知识库文档规则）。

## 项目定位

Azure Vanguard（蔚蓝先锋）是一款**即时战略（RTS）×塔防（TD）融合的 3D 战略游戏**。玩家扮演海上先锋舰队的指挥官：战前从干员中选择至多 6 名编队并携带场内道具；战斗中干员按各自的战略 AI 自动选位作战，也可由玩家指定常驻点位手动驻守；指挥官用场内点数部署干员、复活阵亡干员、建造掩体墙与功能桩塔，抵御沿下沉区推进的敌人波次。

当前阶段定位：**玩法原型优先**。本版策划案聚焦核心战斗循环，验证"点数经济—AI 选位/手动驻守—道具建造—波次防御"的融合乐趣；抽卡、基建、剧情等长线系统只做框架级预留（见 [[04-外围系统预留]]）。

## 设计支柱

1. **融合循环自研。** 敌人侧保留塔防式的波次编排与进攻路径（下沉区内 NavMesh 寻路）；干员侧引入即时战略式的自主移动与玩家驻守指令。核心规则以本系列文档为准，**不再以明日方舟为复刻蓝本**（2026-09-10 改版决定）。
2. **上下层战场。** 地图分上层与下沉区：上层安全，输出/辅助干员常驻；下沉区是敌人唯一活动区，重装干员与掩体墙在此抗线。空间分工构成天然的策略骨架。
3. **点数经济。** 初次部署、复活、道具建造共用一套场内点数，玩家持续在"人、墙、桩"之间做资源决策——这是本作的核心乐趣来源。
4. **3D 卡通表现。** 复用项目卡通 Shader 工具链与 GAS/BehaviorEditor 行为工具链；上下层高度差、道具建造与技能立体特效是表现重点。

## 核心循环

```text
┌────────────┐    ┌────────────────┐    ┌────────────┐
│  编队准备   │ →  │   战斗部署      │ →  │  波次防御   │
│ 选择6名干员 │    │ 消耗点数部署/   │    │ AI选位或    │
│ +携带道具   │    │ 建造掩体墙/桩塔 │    │ 驻守作战    │
└────────────┘    └────────────────┘    └─────┬──────┘
        ↑                                     │ 漏怪扣生命点
        │      ┌────────────────┐             ↓
        │      │  复活与重建     │ ← ┌────────────┐
        │      │ 点数复活/自动   │   │ 胜利/失败   │
        │      │ 复活/点数买道具 │   └────────────┘
        │      └───────┬────────┘
        │              ↓ 击杀/治疗/助攻 → 场内经验 → 伤害成长
┌───────┴───────┐
│  结算与养成    │
│ 材料/信用/经验 │
└───────────────┘
```

- **单局内循环**：点数随时间回复 → 部署干员 / 建造道具 → 干员按自动 AI 或手动常驻点位作战 → 击杀/治疗/助攻转化为场内经验（伤害成长）→ 阵亡干员点数复活或等待自动复活 → 点数再投入掩体墙与桩塔 → 抵御全部波次。
- **局外循环**：通关获得养成资源 → 干员升级变强 → 挑战更高难度。局内成长与局外成长按 **3:7** 分配（见 [[01-核心战斗系统]] 场内经验成长）。

## 战场结构（本版核心概念）

- **上层**：安全平台，可部署输出/辅助职业（穿透/轻装/突击/后援/协同）；地面敌人无法接触上层干员（远程敌人与 Boss 范围技能除外）。
- **下沉区**：敌人唯一活动层，NavMesh 沿预定义路径寻路进攻；仅重装干员可部署于此；掩体墙与功能桩放置于此。
- 上下层不互通；干员部署后锁定所在层，自动移动也不跨层。

## 原型目标

| 维度 | 目标 |
| --- | --- |
| 职业 | 6 职业定位体系（穿透/轻装/重装/突击/后援/协同，见 [[01-核心战斗系统]]），每职业定义自动模式 AI 战略机制 |
| 干员 | 14 名原型干员（轻装 4 / 穿透 4 / 重装 2 / 后援 2 / 协同 1 / 突击 1），单局上场至多 6 名 |
| 场内成长 | 场内经验系统（击杀/治疗/助攻 → 伤害提升），局内:局外成长 = 3:7 |
| 道具 | 掩体墙（≥2 种属性）、防御塔、回血桩、Buff 桩四类；战前携带、场内点数购买放置 |
| 关卡 | 3 个完整规格关卡（教学/标准/Boss）+ 2 个扩展关概要 |
| 敌人 | 7 类敌人模板（普通近战/远程/重甲/快速/法术/精英/Boss） |
| 养成 | 纯等级 1-60 + 技能等级 1-7，不做精英化/潜能/专精 |
| 外围 | 全部占位，不进入原型 |

## 术语表

后续所有策划案文档必须使用以下术语，不得使用同义异名。

| 术语 | 定义 |
| --- | --- |
| 干员 | 玩家可部署的战斗单位，单局至多 6 名。 |
| 层级 | 干员所属层：上层或下沉区；部署后不可跨层。 |
| 上层 | 安全平台，输出/辅助职业的部署层。 |
| 下沉区 | 敌人唯一活动层，NavMesh 寻路；重装与掩体墙在此抗线。 |
| 部署位 | 干员可放置的格子，分**上层位**（输出/辅助）与**下层位**（重装专用）。 |
| 建造位 | 场内道具专用的放置格子，与部署位分开标记。 |
| 常驻点位 | 干员当前驻守的目标位置。自动模式下由 AI 选取并动态调整；手动模式下由玩家指定。 |
| 自动模式 | 干员按本职业 AI 战略机制自行选位移动。按角色独立切换。 |
| 手动模式 | 干员驻守玩家指定的常驻点位，不主动移动。按角色独立切换。 |
| 场内点数 | 战斗内统一资源：初次部署、复活、道具购买放置均消耗，随时间自然回复。 |
| 复活 | 阵亡干员消耗点数立即复活，或等待倒计时自动复活。 |
| 场内经验 | 单局内通过击杀/治疗/助攻积累的经验，转化为伤害成长；每场清零。 |
| 阻挡 | 下沉区内，重装干员与掩体墙使接触的敌人停下交战的能力。 |
| 索敌 | 干员在攻击范围内选择攻击目标的规则。 |
| 技能循环 | 技能点（SP）积攒 → 触发 → 持续 → 结算的完整周期。 |
| SP | 技能点，按触发类型（攻击回复/受击回复/自动回复）积攒。 |
| 拐 / 拐力 | 为友方提供增益（Buff）的支援能力俗称；上拐即施加增益。 |
| 灌伤 | 在短时间内向目标集中倾泻大量伤害。 |
| 副 C | 副输出位，输出能力低于主力输出（DPS）。 |
| 场内道具 | 战前携带种类的建造物：掩体墙/防御塔/回血桩/Buff 桩，战斗中用场内点数购买放置。 |
| 掩体墙 | 放置于下沉区的阻挡建筑，有耐久，可被敌人摧毁。 |
| 防御塔 | 主动攻击范围内敌人的建筑。 |
| 回血桩 | 持续治疗范围内友方的建筑。 |
| Buff 桩 | 为范围内友方提供增益的建筑。 |
| 波次 | 关卡内一批敌人的出怪编排单位（W1、W2……）。 |
| 生命点数 | 关卡防御资源，敌人抵达防线终点扣减，归零即失败。 |
| 理智 | （外围占位）进入关卡的体力消耗，原型不实现。 |
