# 干员与养成

> 本文档为**第二版**玩法设计稿（2026-09-10 RTS×TD 融合改版），描述目标设计而非当前代码现状。术语与字段定义以 [[00-策划案总览]] 术语表和 [[01-核心战斗系统]] 数值骨架为准。

## 干员数据结构

每名干员由以下数据构成（与 01 数值骨架字段一致）：

| 字段 | 说明 |
| --- | --- |
| 代号 | 干员名称，贴合海洋/航空题材。 |
| 职业 | 6 职业之一（穿透/轻装/重装/突击/后援/协同），决定层级与基础模板。 |
| 稀有度 | 3/4/5 星三档（原型简化，不做 6 星）。面板系数：3 星 ×1.00、4 星 ×1.08、5 星 ×1.15。 |
| 层级 | 上层 / 下沉区（仅重装）。部署后锁定所在层，不可跨层。 |
| 面板 | 生命 / 攻击 / 防御 / 法抗 / 部署点数 / 复活点数 / 自动复活时间 / 攻击间隔 / 阻挡数（仅重装）。 |
| 攻击范围 | 以自身为圆心的半径/扇形描述（无朝向概念）。 |
| AI 战略机制 | 自动模式下的选位策略，由职业模板定义（见 [[01-核心战斗系统]] 职业 AI 战略机制表）。 |
| 场内成长系数 | 场内经验升级带来的伤害提升参数（全局 0.3 系数内的职业级微调，默认不调）。 |
| 技能 | 1 个主动技能（原型不做天赋与被动，降低实现量）。 |
| 获取方式 | 原型全部默认解锁。 |

## 成长线（原型精简）

- **等级 1-60**，无精英化、无潜能。升级只提升面板，不改变技能结构。
- 每级成长 = 该干员"满级面板 − 1 级面板" ÷ 59，线性插值。1 级面板 = 满级面板 ÷ 1.6（向下取整），保证前期压力可控。
- 升级消耗：金币 + 经验材料（数值占位，原型可直接免费满级开关，便于测试）。
- **原型提供"测试满级"开关**：调试菜单一键满级，用于关卡难度验证。
- 局外等级/技能成长在伤害公式中作为**局外成长系数**归一化（满级满技能 = 1），与场内成长按 3:7 合成，见 [[01-核心战斗系统]] 场内经验成长。

## 场内成长（局内经验）

- 场内经验每场归零，来源：击杀 / 治疗量折算 / 助攻（详见 [[01-核心战斗系统]]）。
- 场内等级 1-10，升级只提升伤害。
- 干员字段"场内成长系数"默认不调，为后续职业差异化（如"成长型"干员局内权重更高）预留。

## 技能升级

- 技能等级 1-7 级，效果数值随等级线性提升（如 +8 点数 → 每级 +0.5 点数）。
- 1 级默认解锁，7 级为上限；升级消耗金币（原型可免费）。
- 不做专精。

## 编队规则

- 单局编队上限 **6 人**，无职业强制限制；编队即全部战力，战斗中**不可追加**干员。
- 编队界面提示推荐搭配：至少 1 重装（下沉区抗线）、1 后援（治疗）。仅提示，不强制。
- 关卡地图的上层位/下层位数量 ≥6，保证编队全员可部署；建造位另计。

## 场内道具携带（战前准备）

- 战前从道具库选择携带的道具**种类上限 3**（具体道具清单与价格见 [[01-核心战斗系统]] 道具系统）。
- 携带的是"种类"而非数量；战斗中用场内点数按需购买放置，同种同场上限 2 个【待确认】。
- 道具库随原型一次性全解锁，不做获取养成（外围占位见 [[04-外围系统预留]]）。

## 干员获取（原型）

- **全部 14 名干员默认解锁**，无抽卡联动（抽卡为外围占位，见 [[04-外围系统预留]]）。
- 后续接入抽卡时，仅需将"默认解锁"替换为"解锁标记"，干员数据结构不变。
