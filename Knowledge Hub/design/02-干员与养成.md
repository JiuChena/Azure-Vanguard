# 干员与养成

> 本文档为第一版玩法设计稿，描述目标设计而非当前代码现状。术语与字段定义以 [[00-策划案总览]] 术语表和 [[01-核心战斗系统]] 数值骨架为准。

## 干员数据结构

每名干员由以下数据构成（与 01 数值骨架字段一致）：

| 字段 | 说明 |
| --- | --- |
| 代号 | 干员名称，贴合海洋/航空题材。 |
| 职业 | 6 职业之一（穿透/轻装/重装/突击/后援/协同，见 [[01-核心战斗系统]]），决定部署位类型与基础模板。 |
| 稀有度 | 3/4/5 星三档（原型简化，不做 6 星）。面板系数：3 星 ×1.00、4 星 ×1.08、5 星 ×1.15。 |
| 部署位 | 地面位 / 高台位（由职业模板决定）。 |
| 面板 | 生命 / 攻击 / 防御 / 法抗 / 费用 / 再部署时间 / 阻挡数 / 攻击间隔。 |
| 攻击范围 | 以部署格为起点的形状描述（近战自身格、远程十字延伸等）。 |
| 技能 | 1 个主动技能（原型不做天赋与被动，降低实现量）。 |
| 获取方式 | 原型全部默认解锁。 |

## 成长线（原型精简）

- **等级 1-60**，无精英化、无潜能。升级只提升面板，不改变技能结构。
- 每级成长 = 该干员"满级面板 − 1 级面板" ÷ 59，线性插值。1 级面板 = 满级面板 ÷ 1.6（向下取整），保证前期压力可控。
- 升级消耗：金币 + 经验材料（数值占位，原型可直接免费满级开关，便于测试）。
- **原型提供"测试满级"开关**：调试菜单一键满级，用于关卡难度验证。

## 技能升级

- 技能等级 1-7 级，效果数值随等级线性提升（如 +8 DP → 每级 +0.5 DP）。
- 1 级默认解锁，7 级为上限；升级消耗金币（原型可免费）。
- 不做专精（明日方舟的专精二/三在原型中省略）。

## 编队规则

- 原型编队上限 **8 人**，无职业强制限制。
- 编队界面提示推荐搭配：至少 1 后援（治疗）、1 重装（抗线）；回费位待 6 职业体系定义【待确认】。仅提示，不强制。
- 关卡部署位上限（8-9 个）小于编队人数，玩家需根据关卡选择上场干员。

## 干员获取（原型）

- **全部 14 名干员默认解锁**，无抽卡联动（抽卡为外围占位，见 [[04-外围系统预留]]）。
- 后续接入抽卡时，仅需将"默认解锁"替换为"解锁标记"，干员数据结构不变。
