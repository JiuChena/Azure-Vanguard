- **影响**：新文档一律写入知识库（现行结构见 [[_规范/知识库总规范]]）；Obsidian 知识库为统一文档归属（memory：project-docs-knowledge-base）

## 2026-10-14: 知识库重构为"项目文档化"框架（大类→小类）

- **背景**：Hermes 四层为面试库设计，项目文档后期硬塞（5 篇混在学习笔记间、417 行主文档混装）；用户拍板按"大类→小类"全库重分，项目文档以"弱智 AI 也能跟着执行"为标准
- **决策**：
  1. 四层框架舍弃，全库统一按 10 大类重分：_规范 / 01-项目总览 / 02-流程SOP / 03-框架 / 04-模块 / 05-玩法设计 / 06-模板 / 07-更新日志 / 08-踩坑与排查 / 09-决策记录 / 10-学习区
  2. 学习笔记（22 篇）一并纳入新框架（10-学习区收纳，英文文件名不动）
  3. 历史 journal 日志（16 篇日期日志）**原样归档**不重写；quiz 归面试冲刺
  4. 项目文档区新文档**中文命名**；学习区沿用英文命名
  5. 未动工模块（战斗/任务/活动/SDK/服务端）建**骨架占位**（定位/依赖/动工前置清单/挂账）
  6. 日志新规范：批次六字段（模块/内容/原因/验证/关键词/遗留）+ 单卷 ≤1000 行分卷 + 关键词总索引强制（[[_规范/日志规范]]）
- **影响**：所有 `[[]]` 旧路径链接重写；文档维护流程改为"改代码→更文档→写日志→登索引"；接手 AI 首日路径 = HOME → 快捷查询地图 → SOP → 模块文档
