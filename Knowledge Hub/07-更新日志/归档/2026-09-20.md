# 2026-09-20

## Azure Vanguard — HomePanel MVC 重构搭框架

用户把新版式 View 拆成了 5 个分区组件（`View/HomePanel/` 下 `HomePanel_BG` / `HomePanel_PlayerDisplay` / `HomePanel_MenuBar` / `HomePanel_Status` / `HomePanel_Gameplay`），要求写 Control 接管面板控制 + 数据模块，框架先行、TODO 占位。

### 落地内容

- **Control**：`Panels/Control/HomePanel.cs`（继承 `PanelBase`），声明 5 个 View 字段 + `avatarAtlas` + `rarityBgs`；`RefreshPlayerDisplay()` 已移植（头像图集取图兜底默认图 / 昵称 / `Lv.{level}` / 经验条 anchorMax 填充），`SetDisplayCharacter` 移植保留待槽位节点；`EventInit` / `OnUpdate` 全部 TODO 占位。
- **Module**：`Panels/Module/HomePanelModel.cs`，`PlayerInfo` 已接 `PlayerInfoManager`，体力/货币/时间属性占位返回 0/空串。
- **场景接线**（`AgentScripts/HomePanelControlWire.cs`，流程：SaveOpenScenes → 切到 Home.unity → 挂 HomePanel 于 Canvas/HomePanel 根 → 补挂 HomePanel_MenuBar 于 Bot/MenuBar → SerializedObject 接 6 个引用 → 保存 → 切回原场景）：5 个 View 字段 + 图集全部接好。
- **文档**：[[modules/azure-vanguard]] 的 HomePanel 章节重写为 MVC 结构。

### 决策

- MVC 目录约定确立：`View/` 纯字段组件、`Control/` = PanelBase 控制器、`Module/` = 展示数据模型；数据源接入后只改 Module。
- 旧版式根节点 `HomePanel_Temp`（场景）与 `Control/HomePanel_Temp.cs` 暂留参考，删除时机由用户定。

### 注意事项

- `Avatar.spriteatlasv2` 的 packables 在磁盘上被清空（非本会话操作）；未重打包前 `GetSprite` 全部返回 null，UI 走场景默认图兜底。
