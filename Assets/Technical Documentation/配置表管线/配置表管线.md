# 配置表管线技术文档

> 状态：**设计稿（待实现）**——描述 Excel 转 JSON 静态配置管线。创建于 2026-09-10。

## 概述

静态游戏配置（物品定义、商店商品等策划表数据）统一走 **Excel → JSON → 运行时 Catalog** 管线。这类数据不动态变化、由策划维护、行数持续增长，不适合手填 ScriptableObject。

管线分工：

- **Excel（源）**：策划编辑，git 管理，位于项目根 `ConfigTables/`。
- **Python 导出脚本（转换）**：`Tools/ConfigExporter/export_config.py`，命令行手动执行，一键全量导出。
- **JSON（生成物）**：输出到 `Assets/Settings/Config/`，**只读**，禁止手工修改；随包体/Addressables 分发。
- **Catalog（运行时）**：各业务系统的只读索引器，按 ID 建字典。

## 导出工具契约（Python）

- 位置：`Tools/ConfigExporter/export_config.py`；依赖 `openpyxl`（`pip install openpyxl`）。
- 遍历 `ConfigTables/*.xlsx`，每个 Sheet 导出为一个 JSON 文件，文件名 = Sheet 名（小写下划线）。
- **Sheet 结构约定**：第 1 行为字段名（与 JSON 字段一一对应，下划线命名）；第 2 行为中文注释（导出时跳过）；第 3 行起为数据行。
- 空行自动跳过；`item_id` 等主键列重复/为空时报错终止（配置错误 fail-fast，不静默导出）。
- 输出 UTF-8（无 BOM）缩进 JSON。

```text
运行：python Tools/ConfigExporter/export_config.py
输出：Assets/Settings/Config/<sheet_name>.json
```

## 运行时加载约定

- JSON 以 **TextAsset** 形式经 Addressables 加载（key 约定 `config/<文件名>`）；Catalog 类在初始化时 `JsonUtility.FromJson<T>` 解析。
- 运行时统一使用 **Unity 内置 `JsonUtility`**（零第三方依赖）；MessagePack 只用于存档，不用于配置。
- 配置类为纯 `[Serializable]` C# 类，字段名与 Excel 表头一致。
- JSON 是生成物：任何配置修改都必须改 Excel 重新导出，保证源表唯一事实。

## 已规划表

| Sheet/JSON | 内容 | 消费方 |
| --- | --- | --- |
| `item_config.json` | 物品定义：item_id、名称、类型、堆叠上限、图标 key、描述、来源说明 | ItemCatalog（背包） |
| `shop_config.json` | 商品编排：goods_id、item_id、发货数量、价格货币 item_id、单价、限购次数、排序、上架标记 | ShopCatalog（商店） |

后续表（干员表、敌人表、关卡表等）在对应系统拆分时按同一契约加入，不再另行立管线。

## 依赖项

| 依赖 | 说明 |
| --- | --- |
| Python 3.x + openpyxl | 仅导出期需要；运行时零 Python 依赖 |
| Addressables | TextAsset 加载（复用 `AddressableManager`） |
| JsonUtility | Unity 内置，运行时解析 |

## 注意事项

1. **主键唯一**：每张表的主键列（item_id/goods_id）导出时校验唯一与非空。
2. **字段只增不改名**：与存档不同，配置 JSON 无版本迁移问题（随包分发、全量替换），但字段改名会破坏运行时反序列化，表头字段名视为接口契约。
3. **图标等 Unity 资产引用一律用 key 字符串列**（如 `icon_key`），Excel 不引用资产；key 与 Addressables 资源键对齐。
4. **枚举列用整型或约定字符串**（如 kind：`currency/material/battle_item/consumable/misc`），在文档中固化映射表。
5. 导出脚本不进 Unity 工程，不引入任何 Unity 包依赖（2026-09-10 用户确认：外部 Python 脚本形态）。
